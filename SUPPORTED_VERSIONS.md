# Supported Versions

This document describes the support lifecycle for the First Step Technology LLC Compliance-as-Code Platform public repository.

---

# Current Support

The latest version of the public repository receives active maintenance, including:

- Documentation improvements
- Schema updates
- Example updates
- API documentation enhancements
- Integration guide updates
- Bug fixes
- Security documentation updates

---

# Support Policy

| Version | Status | Supported |
|---------|--------|-----------|
| Latest | Active Development | ✅ Yes |
| Previous Releases | Maintenance Only | Limited |
| Archived Releases | End of Support | ❌ No |

# What Is Supported

Supported repository components include:

---

# Security Updates

Security-related updates are prioritized for the latest supported version of the repository.

Older releases may not receive updates.

---

# Versioning

This repository follows Semantic Versioning (SemVer):

```
MAJOR.MINOR.PATCH
```

Example:

```
2.4.1
```

Where:

- **MAJOR** — Breaking changes
- **MINOR** — New functionality
- **PATCH** — Bug fixes and documentation corrections
